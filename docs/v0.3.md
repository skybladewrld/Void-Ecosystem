# Void Flip v0.3 — Living System

## Goal

v0.3 deepens the connected Core Loop without introducing fake networking or shallow extra games. Nyx responds to the device, three complete games feed trusted progression, and long-term collections now survive between sessions.

## Implemented systems

- Nyx behavioral states, temporary event reactions, contextual thoughts, blinking, eye movement, breathing, excited bounce, and sleep motion
- Blackglass Checkers with forced captures, multi-jumps, kings, CPU Easy/Normal/Hard, and reward-free local hot-seat mode
- Per-game mastery XP/levels and twelve persistent one-time challenges
- Two weekly objectives selected per ISO calendar week and a forgiving daily quest streak
- Void Codex states for owned, discovered, and hidden content
- Twenty-two achievements across Companion, Games, Crafting, Economy, Exploration, and Mastery
- Priority notifications, bounded Notification Center history, and optional procedural tones
- Local Profile summary with progression, collection, favorite game, playtime, streak, and mastery data

## Save migration

Schema v3 preserves schema-v2 Flux, quests, inventory, relics, game scores, settings, and Voidling state. It adds mastery, challenges, weekly quests, streaks, Codex discoveries, achievements, notification history, behavior metadata, Blackglass statistics, and profile statistics. Writes remain atomic and retain a `.bak` recovery copy.

## Platform preparation

The hardware boundary now exposes charging, temperature, audio availability, network state, display metadata, and input source. Keyboard events map to named device actions. Future Void Link structures are data definitions only, and the community game API remains a documented trust contract rather than an executable loader.

## Current limitations

Networking, online accounts, trading, Node services, community game execution, emulator launching, Raspberry Pi GPIO, and real battery drivers remain roadmap-only. Desktop battery readings are simulated. Procedural sound depends on an available Pygame mixer and silently disables itself otherwise.

## v0.4 direction

Build Maze Shift as the next complete game, prototype transport-independent local peer discovery behind the documented Void Link boundary, improve resolution-independent layout, and add real Raspberry Pi adapter experiments without coupling them to the application core.
