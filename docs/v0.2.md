# Void Flip v0.2 — Core Loop

## Goal

v0.2 turns separate device modules into a repeatable loop: play, earn, care, buy, craft, complete objectives, unlock, save, and return later.

## Implemented systems

- Dashboard with Nyx summary, battery, Node state, Flux, daily quests, activity, and nine shortcuts
- Flux earned from games, quests, and achievements and spent only in the Void Market
- Three deterministic daily quests selected by local date and auto-claimed on completion
- Six-entry Market with balance validation and controlled Mystery Cache loot
- Level-based Workshop, Market, Signal Serpent, and advanced-relic unlock rules
- Void Merge and Signal Serpent payouts through one duplicate-safe reward service
- Game XP relic modifiers and Prism Compass material bonus through one modifier layer
- Non-blocking notification queue and rolling 75-event activity journal
- Module-specific lower-screen context
- Save schema v2 with v1 migration, atomic replacement, and a previous-save backup

## Save migration

Existing version-1 profiles keep their Voidling, inventory, relics, settings, and Void Merge high score. Migration adds Core Loop defaults for Flux, quests, quest date, unlock history, reward IDs, activity, and Signal Serpent statistics. Saves remain at `%APPDATA%\VoidEcosystem\flip-profile.json`; the preceding version is copied to `flip-profile.json.bak` before replacement.

## Current limitations

Friends, trading, emulator launching, community packages, Void Node networking, and Raspberry Pi drivers remain honest roadmap shells. Local JSON is suitable for this single-player prototype but is not an authority for future shared ownership. Art and audio remain procedural/minimal.

## Next roadmap

v0.3 should focus on Blackglass Checkers, quest variety and rerolls, richer Nyx evolution/animation, audio, input remapping, accessibility, and the first tested Raspberry Pi hardware adapter.
